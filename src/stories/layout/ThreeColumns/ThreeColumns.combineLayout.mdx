# Три колонки

Новый дизайн используется по умолчанию в Column, NoData и EmptyData.

Выберите проект, затем задачу. Проект без задач показывает NoData, отсутствие выбора показывает EmptyData. При смене проекта выбор задачи сбрасывается. Поиск фильтруется родителем, а Column отображает найденные элементы.

<Canvas of={LayoutStories.CombinedLayout} />

Контейнер задаёт высоту, компоненты занимают всё доступное пространство. Шапка Column может менять высоту: список получает остаток автоматически и прокручивается внутри. В примере действия изменения данных скрыты; добавление, редактирование и удаление можно проверить в разделе Column.

Ниже показан только каркас размещения. `projectColumnProps` и `taskColumnProps` — параметры двух независимых списков: данные, поиск, выбранный ID и обработчики. Полный минимальный пример с объявлением параметров находится в [документации Column](?path=/docs/layout-threecolumns-column--docs).

```tsx
<div style={{ display: 'flex', gap: 16, height: '100%', minHeight: 0 }}>
  <Column {...projectColumnProps} />
  <Column {...taskColumnProps} />
  <div style={{ flex: 1, minWidth: 240, minHeight: 0 }}>
    <EmptyData />
  </div>
</div>
```

Принципы оформления и поведения записаны в `docs/design-system.md`.
