# Column

Вертикальный список с выбором элемента, поиском, сортировкой и группами. Подходит для самостоятельного списка или последовательности «проекты → задачи → подробности».

Новый вид включён по умолчанию: поиск занимает всю ширину, `+` добавляет элемент, меню `⋯` в шапке содержит действия с выбранным элементом. Выбор не меняет ширину содержимого строк. `appearance="classic"` включает прежнее оформление.

## Кто управляет данными

Родитель хранит список, выбранный ID, запрос и параметры сортировки. Column сообщает об изменениях через обработчики. **Поиск не фильтрует items автоматически:** передавайте уже отфильтрованный список. `searchFields` выбирает поле, но фильтрацию по нему тоже реализует родитель.

Column сортирует переданные элементы по `sortValue` и `directionValue`, группирует по `groupBy`, управляет раскрытием групп и сохраняет ширину. Обработчики добавления, редактирования и удаления выполняет приложение; сам компонент данные не изменяет.

`selectedItemId` — строка; `''` означает отсутствие выбора. Числовой `item.id` при выборе преобразуется в строку. После удаления выбранного элемента родителю следует сбросить выбор.

## Рабочий пример

Введите запрос, добавьте элемент, выберите строку и откройте `⋯`. Редактирование меняет название, удаление запрашивает подтверждение и показывает загрузку.

## Поиск и счётчик

`items.length` определяет число отображаемых элементов. Передайте `totalItemsCount` до фильтрации, чтобы при непустом запросе показать «Найдено N из M». Без него выводится только N. Очистка поля вызывает `onChangeSearchValue` с пустой строкой.

## Длинные названия и группы

`renderItems` возвращает пользовательское содержимое строки. Column добавляет выбор, фокус и выделение. Структура, метаданные и подсказки принадлежат рендеру: компонент не добавляет Tooltip к произвольному названию автоматически. В этих примерах длинное название обрезает List.Item.Meta, а Tooltip показывает полный текст.

`groupBy` задаёт поле группировки. `renderHeaderGroup` меняет содержимое заголовка, `sortGroups` — порядок групп. Элементы без значения поля попадают в «Без группы». Внутри групп действует та же сортировка элементов.

<Canvas of={ColumnStories.LongGrouped} />

## Пустота и загрузка

Пустой список и отсутствие результатов поиска — разные состояния. При `isLoading` без элементов отображается Skeleton; при загрузке уже имеющегося списка его строки показывают Skeleton. `loadingRemove` относится только к удалению.

## Размеры и кастомный заголовок

Родитель задаёт доступную высоту. Column занимает её целиком: шапка имеет высоту по содержимому, список получает остаток и прокручивается внутри. Не нужно вычитать фиксированную высоту шапки из высоты окна. Для темы область должна наследовать CSS-переменные ConfigProvider.

`title` и `extraTitle` принимают ReactNode. Например, кнопку карты связей можно передать внутри title; её действие остаётся в приложении. Текстовый заголовок может переноситься. `tooltipTitle` меняет подсказку стандартного текстового заголовка; подсказки в кастомном ReactNode задаёт его автор.

В следующем примере нажмите «Показать информацию»: шапка вырастет, список уменьшится при той же высоте колонки. Высоту области можно изменить в панели Storybook.

<Canvas of={ColumnStories.CustomHeader} />

Ширина по умолчанию — 300 px, минимальная раскрытая ширина — 200 px. Тяните правую границу или используйте стрелки на сфокусированной границе. Enter/Space переключают сворачивание, если `isCollapsible` включён. Строка выбирается кликом, Enter или Space. Используйте уникальный `columnKey` для каждой независимой колонки: её ширина хранится в localStorage.

## Минимальная интеграция

Шесть обязательных параметров: `items`, `renderItems`, `selectedItemId`, `setSelectedItemId`, `searchValue`, `onChangeSearchValue`. В примере действия скрыты, потому что обработчики изменения данных не переданы.

```tsx
import { useState } from 'react';
import { List, Tooltip } from 'antd';
import { Column } from 'isp-ui-kit';

type Item = { id: string; name: string };
const items: Item[] = [
  { id: '1', name: 'Личный кабинет' },
  { id: '2', name: 'Интеграции' },
];

export function ProjectList() {
  const [selectedId, setSelectedId] = useState('');
  const [search, setSearch] = useState('');
  const filtered = items.filter((item) =>
    item.name.toLowerCase().includes(search.toLowerCase()),
  );

  return (
    <div style={{ display: 'flex', height: 500, minHeight: 0 }}>
      <Column<Item>
        title="Проекты"
        columnKey="projects"
        items={filtered}
        totalItemsCount={items.length}
        selectedItemId={selectedId}
        setSelectedItemId={setSelectedId}
        searchValue={search}
        onChangeSearchValue={(value) => setSearch(value)}
        renderItems={(item) => (
          <List.Item>
            <Tooltip title={item.name}>
              <List.Item.Meta title={item.name} />
            </Tooltip>
          </List.Item>
        )}
        showAddBtn={false}
        showUpdateBtn={false}
        showRemoveBtn={false}
      />
    </div>
  );
}
```
