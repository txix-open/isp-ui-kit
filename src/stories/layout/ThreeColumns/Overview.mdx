# ThreeColumns

Column — выбор и поиск по списку. NoData — данных нет. EmptyData — элемент ещё не выбран. Все три используют новый дизайн по умолчанию и занимают высоту родителя.

## Рабочий сценарий

Выберите проект, затем задачу. Смена проекта сбрасывает выбор задачи; проект «Новый проект» показывает отсутствие данных. Поиск фильтрует реальные данные.

<Canvas of={LayoutStories.CombinedLayout} />

## Что проверить

- Переключить тему, ширину и высоту в панели Storybook.
- Изменить ширину колонки мышью или стрелками на сфокусированной границе.
- Свернуть/развернуть колонку, выбрать строку через Enter или Space.
- В примере «Действия со списком» раздела Column открыть меню выбранного элемента; проверить отмену и подтверждение удаления.
- Проверить длинные названия и перенос заголовка: поиск сохраняет всю ширину, список получает остаток высоты.

## Другие сценарии

В разделе Column есть поиск, сортировка, CRUD, загрузка, отсутствие результатов и кастомный рендер. [Сложные преобразователи и модули](?path=/story/редизайн-column--playground) позволяют сравнить новый и прежний вид на одном наборе данных.

Подробные правила и API доступны в документации Column. `appearance="classic"` сохраняется для миграции; основной пример показывает новый дизайн.
