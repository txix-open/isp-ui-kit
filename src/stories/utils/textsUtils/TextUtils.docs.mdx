# Тексты приложения

Функции получают словарь от приложения. Они не загружают тексты, не создают store и не требуют React Context. Конкретный словарь сохраняет типизацию ключей; `Record<string, string>` позволяет работать с динамическими ключами.

```tsx
import {
  getText,
  createTextGetter,
  verifyTextKey,
  createTextVerifier,
  type TextDictionary,
  type TextParams,
} from 'isp-ui-kit';

const texts = {
  'table.empty': 'Нет данных',
  'table.count': 'Всего: {{count}}',
  'table.note': '',
} as const satisfies TextDictionary;
const params: TextParams = { count: String(3) };

const empty = getText(texts, 'table.empty'); // 'Нет данных'
const count = getText(texts, 'table.count', '', params); // 'Всего: 3'
```

TextDictionary — `Record<string, string>`; TextParams — `Record<string, string>`. Числа преобразуйте в строки явно. Функции не выполняют склонение, плюрализацию, форматирование дат или HTML-экранирование. Отображайте результат как обычный React-текст.

## getText

`getText(texts, key, fallback?, params?): string` возвращает текст по ключу. Если словарь отсутствует, результат — fallback или пустая строка. Если словарь есть, отсутствующее собственное свойство или nullish значение заменяется fallback, затем пустой строкой. Существующая пустая строка сохраняется и не заменяется fallback.

При переданных params все совпадения шаблона подставляются в текст, в том числе в fallback, если словарь существует. При texts=undefined fallback возвращается сразу, **без подстановки**. Неизвестные параметры остаются в тексте.

Имена параметров и значения подставляются буквально: точки и скобки в именах не имеют смысла регулярного выражения, `$&` в значении остаётся текстом. Учитываются только собственные свойства params.

## createTextGetter

`createTextGetter(texts)` возвращает функцию `(key, fallback?, params?) => string` с тем же поведением getText. С конкретным словарём TypeScript ограничивает key его известными ключами.

```tsx
import { createTextGetter, type TextDictionary } from 'isp-ui-kit';

const texts = {
  'table.empty': 'Нет данных',
  'table.count': 'Всего: {{count}}',
} as const;
const text = createTextGetter(texts);
const count = text('table.count', '', { count: String(3) });
// text('unknown.key') — ошибка TypeScript для этого словаря.

// Для словаря с сервера допускаются произвольные строковые ключи.
const serverTexts: TextDictionary = { 'table.empty': 'Нет данных' };
const dynamicText = createTextGetter(serverTexts);
const fallback = dynamicText('unknown.key', 'Текст по умолчанию');

// До загрузки словаря fallback работает без подстановки параметров.
const pendingText = createTextGetter<TextDictionary>(undefined);
const loading = pendingText('table.empty', 'Тексты загружаются');
```

Фабрика привязывается к переданному словарю. При загрузке другого словаря создайте новую функцию; она не подписывается на изменения внешней переменной.

## verifyTextKey

`verifyTextKey(texts, key): boolean` проверяет собственное свойство словаря и возвращает Boolean его значения. Это проверка непустого текста: существующая пустая строка даёт false. Свойства прототипа не считаются текстами. Для проверки наличия свойства независимо от значения используйте Object.hasOwn в приложении.

```tsx
import { verifyTextKey, type TextDictionary } from 'isp-ui-kit';

const texts: TextDictionary = { 'table.empty': 'Нет данных', 'table.note': '' };
const available = verifyTextKey(texts, 'table.empty'); // true
const empty = verifyTextKey(texts, 'table.note'); // false
const missing = verifyTextKey(texts, 'unknown.key'); // false
const ownKey = Object.hasOwn(texts, 'table.note'); // true
```

## createTextVerifier

`createTextVerifier(texts)` возвращает типизированную функцию `(key) => boolean` с поведением verifyTextKey. Чтобы проверять произвольный ключ из внешних данных, задайте словарь как TextDictionary; конкретный словарь ограничивает допустимые ключи в TypeScript.

## Использование с React Context

Context — способ приложения передать общую функцию дочерним компонентам; он не требуется утилитам. Пример сохраняет типизацию ключей и проверяет наличие провайдера.

```tsx
import { createContext, useContext, useMemo, type ReactNode } from 'react';
import { createTextGetter, type TextDictionary } from 'isp-ui-kit';

const defaultTexts = { 'table.empty': 'Нет данных' } as const;
type TextKey = keyof typeof defaultTexts;
type GetAppText = (key: TextKey, fallback?: string) => string;
const TextsContext = createContext<GetAppText | null>(null);

export function TextsProvider({
  texts,
  children,
}: {
  texts: TextDictionary | undefined;
  children: ReactNode;
}) {
  const text = useMemo(() => createTextGetter(texts), [texts]);
  return <TextsContext.Provider value={text}>{children}</TextsContext.Provider>;
}

export function EmptyMessage() {
  const text = useContext(TextsContext);
  if (!text) throw new Error('EmptyMessage требует TextsProvider');
  return <p>{text('table.empty', defaultTexts['table.empty'])}</p>;
}
```
