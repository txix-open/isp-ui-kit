# Компоненты данных

Поиск, таблица и просмотр JSON. Эти компоненты не требуют React Hook Form: состояние данных, запросы и действия задаёт приложение.

```tsx
import { SearchInput, ConfigTable, ReactJsonView } from 'isp-ui-kit';
```

## [SearchInput](?path=/docs/components-searchinput--docs)

Текстовое поле Ant Design с иконкой поиска и очисткой. Передавайте `value` и `onChange` для управляемого ввода; размер, disabled, readOnly и status задаются через Input props. Компонент не фильтрует данные и не добавляет debounce: приложение определяет, когда выполнять поиск.

## [ConfigTable](?path=/docs/components-configtable--docs)

Ant Design Table с панелью поиска и кнопкой добавления. Приложение передаёт `columns`, `dataSource`, `rowKey` и обработчики. `onSearch` получает запрос после Enter или кнопки поиска; загрузку, фильтрацию и серверную пагинацию реализует приложение.

`appearance="modern"` используется по умолчанию, `appearance="classic"` сохраняет прежнее оформление. Счётчики задаются через `totalItemsCount` и `filteredItemsCount`; действия для выбранных строк — через `selectionActions` вместе с `rowSelection.selectedRowKeys`.

## [ReactJsonView](?path=/docs/components-reactjsonview--docs)

Отдельный legacy-компонент для просмотра и редактирования JSON с локальными расширениями. Он сохраняет собственную реализацию, API и оформление и исключён из редизайна. Его возможности и примеры описаны на странице компонента.
