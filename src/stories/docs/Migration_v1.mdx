# Переход на версию 1.0.0

Архивная инструкция для перехода со старых групповых импортов на API версии 1.0.0. Для текущего редизайна используйте [новое руководство по переходу](?path=/docs/переход-на-версию-3-0-0--docs). Устанавливать 1.0.0 в новый проект ради этой инструкции не требуется.

## Что изменилось

В версии 1.0.0 компоненты, хуки и утилиты экспортируются по именам из корня библиотеки. Групповой объект FormComponents больше не используется. Глубокие импорты из dist заменяются корневыми; exports этой версии открывает только точку входа пакета.

Эта статья описывает изменение импортов. Она не описывает нынешний редизайн, Ant Design 6 или последующие изменения ReactJsonView.

## Установка версии и зависимостей

Для воспроизведения именно перехода на 1.0.0 установите точную версию:

```bash
npm install isp-ui-kit@1.0.0
```

peerDependencies ниже сверены с package.json коммита выпуска 1.0.0 (`d257bc0`), а не с текущей веткой:

```json
{
  "@monaco-editor/react": "^4.7.0",
  "antd": ">=5.12",
  "monaco-editor": "^0.55.1",
  "react": ">=18",
  "react-dom": ">=18",
  "react-hook-form": "^7.67.0"
}
```

Проверьте уже установленные зависимости приложения и установите недостающие совместимые версии. Эти исторические диапазоны не являются рекомендацией обновить все зависимости до latest. Для другого релиза проверяйте именно его package.json/peerDependencies.

## Замена импортов

Было:

```tsx
import { FormComponents } from 'isp-ui-kit';

const { FormInput, FormRadioGroup, FormSelect } = FormComponents;
```

Стало:

```tsx
import { FormInput, FormRadioGroup, FormSelect } from 'isp-ui-kit';
```

Аналогично импортируются компоненты Layout и компоненты общего назначения:

```tsx
import { Column, EmptyData, SearchInput, ConfigTable } from 'isp-ui-kit';
import type { FormInputProps } from 'isp-ui-kit';
```

Удалите обращения к прежним групповым объектам и глубокие импорты. Props компонента менять только из-за замены способа импорта не требуется; React Hook Form, обработчики и данные приложения остаются в его коде.

## Проверка приложения

- Найдите оставшиеся групповые и глубокие импорты isp-ui-kit и замените их именованными.
- Запустите проверку TypeScript и сборку командами своего приложения. npm run build относится к приложению, в котором вы выполняете миграцию.
- Если у приложения есть Storybook, соберите его и проверьте изменённые примеры.
- Откройте реальные страницы с формами, таблицей и колонками; проверьте ввод, валидацию, выбор и обработчики.
- Проверьте, что сборка больше не сообщает об отсутствующих экспортах или недоступных подпапках dist.

Для перехода сразу на более новую версию дополнительно выполните её руководство по миграции. Изменение импортов в 1.0.0 не покрывает все изменения последующих выпусков.
