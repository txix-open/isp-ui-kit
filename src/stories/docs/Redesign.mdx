# Редизайн UI-кита

Рабочая площадка для постепенного обновления **Layout, Components и FormComponents**. PcsKit остаётся в текущем дизайне и не получает новую рамку темы.

[Руководство по переходу](?path=/docs/редизайн-переход-на-обновлённый-кит--docs): изменения, сохранённые defaults, новые опции и примеры интеграции.

## Как смотреть примеры

В верхней панели Storybook доступны **Тема** (светлая/тёмная), **Ширина** (вся область, 768 или 360 px) и **Высота** (320, 560 или 720 px для ThreeColumns). Настройки сохраняются при переходе между примерами. В документации несколько Canvas могут показывать один и тот же компонент — настройки темы распространяются на них.

Узкая область специально показывает переполнение: многоколоночный интерфейс прокручивается горизонтально, а шапка отдельной колонки переносит текст. Это проверка ограничений, а не обещание мобильной версии каждого компонента.

## Стандарт для следующих этапов

Каждому компоненту нужен рабочий пример и отдельные случаи: обычные/длинные данные, пустота, загрузка, ошибка (где поддержана), disabled/readOnly, ограниченная ширина и клавиатура. Переданные действия должны работать; не использовать кнопки без результата как основной пример.

Для формы показывать результат отправки и реальные ошибки валидации. Для таблицы — поиск, длинные значения, выбор и пагинацию. Для меню — переходы, вложенность и сворачивание. Для сложных редакторов — длинные данные, прокрутку и режим просмотра.

Примеры не означают, что компонент уже переработан. Статус этапа фиксируется отдельно.

## Принципы

Спокойные поверхности, мягкая тень рабочих областей, компактные списки, полноценная ширина поиска, ясные состояния и доступный фокус. Выбор не меняет геометрию строк. Цвет и радиусы берём из согласованных правил, оформление бизнес-содержания остаётся у приложения.

Источники в репозитории: `docs/design-system.md` — принципы и решения; `docs/redesign-plan.md` — порядок работ и критерии завершения. При следующем этапе обновлять оба файла и этот обзор.

Поля формы сохраняют базовые размеры, радиусы, цвета и фокус Ant Design, чтобы сочетаться с обычными Ant Design-компонентами на странице. Для них обновляем интеграцию, обязательность и доступность без отдельного визуального стиля.
