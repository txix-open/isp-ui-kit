# Каркас и рабочие области

Компоненты для навигации, колончатого интерфейса и служебных страниц. Роутинг, загрузка данных и бизнес-действия остаются в приложении.

```tsx
import {
  Column,
  EmptyData,
  NoData,
  LayoutMenu,
  LayoutSider,
  HomePage,
  ErrorPage,
  NotFoundPage,
} from 'isp-ui-kit';
```

## Три колонки

[Column](?path=/docs/layout-threecolumns-column--docs) — список с выбором, поиском, сортировкой и группами. Родитель передаёт данные, выбранный id и обработчики. Поиск и подготовка данных выполняются приложением; ширина и раскрытие групп управляются внутри Column.

modern используется по умолчанию; classic сохраняет прежнее оформление. title может содержать пользовательские действия. Перетаскивание границы меняет ширину, отдельная кнопка сворачивает колонку.

Для стилей Column включите CSS variables Ant Design и подключите стили библиотек прокрутки и изменения размера один раз в приложении:

```tsx
import type { ReactNode } from 'react';
import { ConfigProvider, Layout } from 'antd';
import 'react-resizable/css/styles.css';
import 'simplebar-react/dist/simplebar.min.css';

export function Workspace({ children }: { children: ReactNode }) {
  return (
    <ConfigProvider theme={{ cssVar: {} }}>
      <Layout style={{ height: '100vh', minHeight: 0 }}>{children}</Layout>
    </ConfigProvider>
  );
}
```

Высоту задаёт родитель. Шапка может менять высоту при переносе title или появлении действий; список занимает оставшуюся область и прокручивается внутри. На узком экране общему контейнеру колонок может понадобиться горизонтальная прокрутка.

[Обзор ThreeColumns](?path=/docs/layout-threecolumns-обзор--docs) объясняет данные и компоновку; [сложные списки](?path=/story/редизайн-column--playground) показывают группы, версии и пользовательский title.

### [EmptyData](?path=/docs/layout-threecolumns-emptydata--docs)

Ожидание выбора элемента. Данные в списке могут быть, но зависимую область ещё нечем заполнить. Родитель решает, когда показывать состояние; компонент не следит за selectedItemId.

### [NoData](?path=/docs/layout-threecolumns-nodata--docs)

Отсутствие данных для отображения. Компонент не загружает данные и не проверяет список. content заменяет стандартную иконку и сообщение. Для ожидания выбора используйте EmptyData.

## Навигация

[LayoutSider](?path=/docs/layout-layoutsider--docs) — Ant Design Sider с отдельной прокруткой содержимого и кнопкой сворачивания внизу панели. Поддерживает collapsed, onCollapse, breakpoint, collapsedWidth и пользовательский trigger. Внутри ограниченного каркаса задавайте `style={{ height: '100%' }}` при определённой высоте родителя; прежняя высота по умолчанию — calc(100vh - 45px).

[LayoutMenu](?path=/docs/layout-layoutmenu--docs) — меню по конфигурации. key — уникальный идентификатор, route — алиас первого сегмента пути. onClickItem передаёт выбор приложению; currentPath обновляет активный пункт. Скрытие по разрешениям задаётся через onHideMenuItem, а проверка доступа остаётся в маршрутах приложения.

[Пример подключения React Router и вложенных адресов](?path=/docs/layout-интеграция-с-react-router--docs).

## Страницы

- [HomePage](?path=/docs/layout-pages-homepage--docs) — центрирует children в выделенной области; backgroundImage задаёт фон. Высота по умолчанию 100%, поэтому высоту задаёт родитель.
- [ErrorPage](?path=/docs/layout-pages-errorpage--docs) — сообщение ошибки 500. children — действия в Result.extra; повторную загрузку и переход реализует приложение.
- [NotFoundPage](?path=/docs/layout-pages-notfoundpage--docs) — сообщение 404 и пользовательские действия. Маршрут для неизвестного адреса настраивает приложение.

У ErrorPage и NotFoundPage для совместимости сохранена высота 100vh. Под шапкой передавайте `style={{ height: '100%' }}` и задавайте высоту области содержимого.
