# Хуки

В публичном API кита доступен [useAuth](?path=/docs/hooks-useauth--docs). Он выполняет POST-запросы basic/OAuth-входа и выхода и хранит состояние загрузки внутри конкретного вызова хука.

```tsx
import { useAuth } from 'isp-ui-kit';

export function AuthStatus() {
  const { isLoading } = useAuth();
  return (
    <span>{isLoading ? 'Запрос выполняется' : 'Нет активного запроса'}</span>
  );
}
```

Каждый вызов создаёт отдельное состояние. Чтобы кнопка входа и другие части приложения видели одну сессию, вызывайте хук один раз в провайдере приложения и передавайте результат через Context.

Хук не хранит токены, не восстанавливает сессию, не выполняет переходы OAuth и не защищает маршруты. Пути запросов, заголовки и менеджер сессии задаёт приложение.

Статус меняется после успешного запроса и разбора ответа; ошибка сохраняет прежний isLogged. Флаг isLoading учитывает все текущие запросы этого экземпляра. Получение OAuth loginUrl ещё не подтверждает серверную сессию — проверку доступа выполняет приложение. Подробные контракты, пример с catch и особенности ошибок — [на странице useAuth](?path=/docs/hooks-useauth--docs).
