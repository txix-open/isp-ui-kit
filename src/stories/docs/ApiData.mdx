# Работа с данными API

Приложение вызывает API и передаёт данные компоненту. Компонент отображает их и сообщает приложению о действиях пользователя через функции вроде `onSearch` и `onSubmit`. В API остаются правила валидации, права доступа и работа с данными.

## Список, поиск и страницы

Введите «уведомлений» и нажмите Enter или «Найти». Перейдите на вторую страницу и раскройте **«Запрос и ответ»**. Видно, как меняется `page` при переключении страницы и как `total` отличается от числа записей в `items`. Данные примера вычисляются локально.

Формат `{ items, total }` показан как пример ответа. Если сервер возвращает `{ data, count }`, приложение передаёт `data` в `dataSource`, а `count` — в `pagination.total`.

Пустой список и поиск без совпадений имеют разные состояния. Попробуйте [пустой список](?path=/story/components-configtable--empty) и [поиск без результатов](?path=/story/components-configtable--no-results).

## Редактирование записи

1. Приложение загружает запись. Для отдельных полей оно задаёт начальные значения формы. В `ConfigForm` описание полей передаётся в `config.fields`, а редактируемая запись — первым элементом `data`.
2. Имена полей, например `name` и `description`, определяют ключи в объекте, который получает `onSubmit`. Приложение преобразует его в формат запроса API, если форматы различаются.
3. `onSubmit` возвращает промис сохранения. Пока он выполняется, `ConfigForm` показывает загрузку. Если промис отклонён, форма сообщает об ошибке и сохраняет введённые значения.

## Просмотр вложенного ответа

`ReactJsonView` принимает объект или массив в `src`. Если ответ пришёл строкой, приложение разбирает JSON и обрабатывает возможную ошибку разбора. Для поиска по данным можно передать строку в `search`. Если нужен ввод и изменение JSON как текста, используйте `FormCodeEditor`.
