# Регрессионные проверки

После установки зависимостей пакета:

```sh
node --test tests/utils.test.mjs
```

Проверяются буквальная подстановка параметров, свойства прототипа, пустые тексты, fallback и SSR-чтение конфигурации.

Для useAuth запустите временный локальный Vite:

```sh
npx vite --host 127.0.0.1 --port 6008 --strictPort
```

Откройте `http://127.0.0.1:6008/tests/useAuth.browser.html`. Успех: `document.body.dataset.result === 'passed'` и шесть строк результатов. При ошибке атрибут равен failed, последняя строка содержит причину. После проверки остановите сервер.

Проверки используют настоящий React и React DOM. fetch подменяется только в этой тестовой странице и восстанавливается после завершения; запросов к API и сохранения токенов нет. Проверяются HTTP-ошибки basic/OAuth, ошибка сети и JSON, синхронное исключение, успешные вход/выход, пустой ответ logout, сохранение статуса при ошибке выхода и параллельные запросы.
