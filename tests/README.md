# Регрессионные проверки

Для исправлений редизайна запустите `npx vite --host 127.0.0.1 --port 6008 --strictPort` и откройте `http://127.0.0.1:6008/tests/redesign.browser.html`. Успех: `document.body.dataset.result === 'passed'` и семь строк результатов. Проверяются фокус после добавления/удаления, пустые черновики и внешний reset обеих коллекций, ошибка сохранения с повторной отправкой и восстановление источника вариантов. Дополнительно проверяются фокус во вложенном массиве ConfigForm, запоздалая ошибка после смены записи, чтение null-границ периода, выбор обоих открытых диапазонов через presets, полный период и очистка. Страница использует настоящий React и Ant Design, API заменены локальными сценариями.

В Storybook подключена панель Accessibility (`@storybook/addon-a11y`). Проверять её для светлой/тёмной темы и основных состояний компонентов. Режим `a11y.test: 'todo'` не блокирует CI; это не подтверждение отсутствия нарушений.

После установки зависимостей пакета:

```sh
node --test tests/utils.test.mjs
```

Проверяются буквальная подстановка параметров, свойства прототипа, пустые тексты, fallback и SSR-чтение конфигурации.

Для useAuth запустите временный локальный Vite:

```sh
npx vite --host 127.0.0.1 --port 6008 --strictPort
```

Откройте `http://127.0.0.1:6008/tests/useAuth.browser.html`. Успех: `document.body.dataset.result === 'passed'` и шесть строк результатов. При ошибке атрибут равен failed, последняя строка содержит причину. После проверки остановите сервер.

Проверки используют настоящий React и React DOM. fetch подменяется только в этой тестовой странице и восстанавливается после завершения; запросов к API и сохранения токенов нет. Проверяются HTTP-ошибки basic/OAuth, ошибка сети и JSON, синхронное исключение, успешные вход/выход, пустой ответ logout, сохранение статуса при ошибке выхода и параллельные запросы.
